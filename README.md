# Swift TrueType Hinting Interpreter

Apple's TrueType hinting bytecode interpreter, written in memory-safe Swift.

Published as a reference for writing high performance Swift.

## Building

```sh
swift build
```

Requires macOS 27.0 or later (Xcode 27 or later).

## Testing

```sh
swift test
```
